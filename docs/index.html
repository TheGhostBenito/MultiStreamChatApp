User GuideGuía de uso

Step-by-step instructions to connect each platform. Instrucciones paso a paso para conectar cada plataforma.

Twitch

  1. Open Settings (gear icon) → Platforms → Twitch.Abre Ajustes (icono engranaje) → Plataformas → Twitch.
  2. Enter the channel name (e.g. ibai), without #.Introduce el nombre del canal (ej. ibai), sin #.
  3. Optionally paste an OAuth token for authenticated chat.Opcionalmente pega un token OAuth para chat autenticado.
  4. Tap "Save & Connect".Pulsa "Guardar y Conectar".
Anonymous connections use justinfan accounts automatically.Las conexiones anónimas usan cuentas justinfan automáticamente.

YouTube

  1. Paste a Video ID (11 chars), a watch URL, or a channel handle (e.g. @midudev).Pega un Video ID (11 caracteres), una URL de watch o un handle de canal (ej. @midudev).
  2. The app resolves the active live stream and its chat.La app resuelve el directo activo y su chat.
  3. Tap "Save & Connect".Pulsa "Guardar y Conectar".
Super Chats are shown with a gold highlight.Los Super Chats se muestran con resaltado dorado.

Kick

  1. Enter a slug (e.g. westcol) or a numeric channel id.Introduce un slug (ej. westcol) o un id de canal numérico.
  2. The app resolves the channel and starts polling messages.La app resuelve el canal e inicia el polling de mensajes.
  3. Tap "Save & Connect".Pulsa "Guardar y Conectar".
Kick emotes are parsed from [emote:id:name] tokens.Los emotes de Kick se parsean desde tokens [emote:id:name].

TikTok

  1. Enter the username without @ (e.g. streamer).Introduce el usuario sin @ (ej. streamer).
  2. The app checks the live room and opens a WebSocket.La app verifica la sala en vivo y abre un WebSocket.
  3. Alternatively paste a relay WebSocket URL (TikTok-Live-Connector / EulerStream) in the token field.Alternativamente pega una URL de relay WebSocket (TikTok-Live-Connector / EulerStream) en el campo token.
Only live rooms can connect; offline accounts show an error.Solo las salas en vivo pueden conectar; las cuentas offline muestran error.

  • AppearanceApariencia: Theme (System/Light/Dark), high contrast, text scale 80–150%.Tema (Sistema/Claro/Oscuro), alto contraste, escala de texto 80–150%.
  • ChatChat: Keep screen on, show emotes, show test bar.Pantalla despierta, mostrar emotes, barra de simulación.
  • PlatformsPlataformas: Channel + token per service, connect/disconnect.Canal + token por servicio, conectar/desconectar.

ArchitectureArquitectura

MVVM with a unified repository aggregating all platform clients. MVVM con un repositorio unificado que agrega todos los clientes por plataforma.

MainActivity
↓
ChatViewModel
↓
UnifiedChatRepository
↓
Twitch / YouTube / Kick / TikTok clients

Messages are merged into a Channel, batched (90 ms / 200 msgs) and exposed as a StateFlow. Connection states are combined from all four clients. Los mensajes se fusionan en un Channel, se agrupan (90 ms / 200 msgs) y se exponen como StateFlow. Los estados de conexión se combinan de los cuatro clientes.
